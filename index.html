How to Use This Vault & Security Guide

1. One-Time Free Setup (For Mobile Access)

  1. Mobile browsers block Web Crypto on raw local files (file://). Host this single file for free on GitHub Pages or Cloudflare Pages (rename it to index.html).
  2. Protect your GitHub/Cloudflare account with 2FA so nobody can tamper with the file.
  3. Open your hosted HTTPS link on your phone and tap Add to Home Screen so it behaves like a native app.
  4. Everything runs strictly inside your browser memory—your password and text are never sent over the internet.

2. Encrypting & Saving to Google Drive

  1. Enter a strong master password (aim for 16+ characters or 4–5 unrelated words with numbers/symbols).
  2. Type or paste your credentials into Input (or load an existing .txt file).
  3. Tap Encrypt. The output starts with V1: and looks like random text.
  4. Tap Download .txt and upload that encrypted file to your Google Drive. Delete any unencrypted copies from your device.

3. Decrypting on the Go (Phone or Laptop)

  1. Open your bookmarked vault page.
  2. Tap Load File and pick your encrypted .txt file directly from Google Drive (or copy-paste the V1:... text).
  3. Enter your master password and tap Decrypt.
  4. Your credentials appear in Output. A 2-minute auto-clear timer automatically wipes all fields if you forget to tap Clear All.

4. Critical Rules to Stay Safe

  • No Password Recovery: If you forget your master password, the file is permanently unrecoverable. Keep a written copy of your master password locked somewhere physically safe.
  • Clean Your Clipboard: After copying a password from Output, copy something harmless so the credential doesn't sit in your clipboard history.
  • Keep Backups: Save a spare copy of your encrypted .txt file (e.g., on an external drive or secondary cloud folder) in case you accidentally overwrite it.
